# Установка TruckoRig на iPhone с Windows

Сборка для бесплатного Apple ID. Платный Apple Developer Program не нужен. Профиль живёт 7 дней, потом приложение нужно поставить заново тем же способом.

Нужен iPhone с iOS 17 или новее и кабель.

## 1. Скачать файл

1. Откройте вкладку Actions репозитория.
2. Слева выберите **Sideload IPA**. Сборка появляется после каждого push в `main` и на pull request. Свою можно запустить кнопкой **Run workflow**.
3. Откройте зелёный запуск и внизу скачайте артефакт **TruckoRig-unsigned-ipa**.
4. Распакуйте скачанный zip. Внутри лежит `TruckoRig-unsigned.ipa`. В Sideloadly открывайте именно `.ipa`, не внешний zip.

## 2. Поставить через Sideloadly

1. Установите [iTunes с сайта Apple](https://www.apple.com/itunes/) (не из Microsoft Store) или приложение Apple Devices, чтобы Windows увидела iPhone.
2. Установите [Sideloadly](https://sideloadly.io/).
3. Подключите iPhone, разблокируйте его и нажмите «Доверять этому компьютеру».
4. Перетащите `TruckoRig-unsigned.ipa` в Sideloadly.
5. Введите Apple ID. Подойдёт обычный бесплатный. Пароль уходит в Apple, не в репозиторий.
6. Нажмите Start. На iPhone может появиться запрос код-пароля Apple ID.

## 3. Доверить разработчика и включить режим разработчика

1. На iPhone: **Настройки → Основные → VPN и управление устройством**.
2. Под именем вашего Apple ID нажмите на профиль и выберите **Доверять**.
3. **Режим разработчика**: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Если пункта ещё нет, он появляется после первой установки. Включите его и дайте телефону перезагрузиться.

После этого откройте TruckoRig с домашнего экрана.

## 4. Каждые 7 дней

Бесплатная подпись Apple истекает через 7 дней. Приложение не удалится само, но перестанет открываться. Снова скачайте артефакт (или возьмите тот же `.ipa`) и поставьте его через Sideloadly ещё раз. Журнал на телефоне при этом сохраняется, пока вы не удаляете приложение.

## Чем эта сборка отличается

В обычной сборке из Xcode остаются iCloud, виджет и подписка. В этом файле их нет: так бесплатный Apple ID может подписать приложение.

- Нет iCloud Drive и синхронизации фото.
- Нет виджета на домашнем экране и общей группы приложений.
- Экран Premium не закрывает функции: камера, сканер, отчёты, карта, налог, цель и экспорт открыты без оплаты.
